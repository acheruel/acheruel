## Anthony Chéruel

Outils web pour l'ingénierie des ponts et des structures. Ils s'ouvrent dans le navigateur, sans installation ni compte.
*Web tools for bridge and structural engineering, running in the browser.*

**Site : [acheruel.github.io](https://acheruel.github.io)**

- [QuickerBridge](https://acheruel.github.io/QuickerBridge/) : poutres continues de pont
- [QuickerAtlas](https://acheruel.github.io/QuickerAtlas/) : atlas des ouvrages d'art du Québec
- [BridgeSketch 3D](https://acheruel.github.io/BridgeSketch-3D/) : configurateur 3D de ponts
- [QuickerUnits](https://acheruel.github.io/QuickerUnits/) : convertisseur d'unités
- [Extracto Commento](https://acheruel.github.io/Extracto-Commento/) : commentaires PDF vers Excel
