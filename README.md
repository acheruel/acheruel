## À propos

Bonjour/Hi,

**My github website : [acheruel.github.io](https://acheruel.github.io)**

*Some custom Web tools for bridge and structural engineering (and more), running in the browser. Made for myself out of curiosity and for learning. Always check the results before designing something with it !*

- [QuickerBridge](https://acheruel.github.io/QuickerBridge/) : poutres continues de pont
- [QuickerAtlas](https://acheruel.github.io/QuickerAtlas/) : atlas d'ouvrages d'art au Québec (et ailleurs), proposition de visualisation à partir de l'inventaire du MTMD
- [BridgeSketch 3D](https://acheruel.github.io/BridgeSketch-3D/) : esquisse rapide 3D de ponts pour visualisation uniquement
- [QuickerUnits](https://acheruel.github.io/QuickerUnits/) : convertisseur d'unités sur-mesure pour un ing. structure
- [Extracto Commento](https://acheruel.github.io/Extracto-Commento/) : extracteur simple et rapide des commentaires de fichiers PDF vers un fichier Excel
